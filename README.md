# اغرس غرساً واترك أثراً | درع غابات سوريا الذكي

تطبيق خريطة تفاعلية حقيقية لسوريا مبني باستخدام مكتبة **Leaflet** وصور الأقمار الصناعية، يعرض النطاقات البيئية الستة بحدود شفافة تفاعلية مع الدليل العلمي للأشجار الحراجية والمثمرة ومواسم الغرس.

## طريقة التشغيل
1. فك الضغط عن الملف.
2. افتح ملف `index.html` في أي متصفح إنترنت.
